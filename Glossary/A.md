# Glossary: A

### Abandonment path
- **Category:** game term
- **Also called:** Not My Problem path
- **Definition:** In Inner Tepenia, the fifth ending slot in every Personal Questline Summary, beside Good, Neutral, Bad and Secret/Hidden: what happens if the player walks away from the character's problem. It applies the core design pillar that the player can always say "not my problem" and still reach a valid conclusion.
- **Status:** project canon (design pillar)
- **Used in:** InnerTepeniaGDD; Outer Tepenia series; DerivationMechanisms
- **Sources:** InnerTepeniaGDD `Worldspace/Characters/Dolls/z-template/Questlines/Personal_Questline_Summary.md`; `Storyline/Endings/Secret-Endings/Hidden_Paths_And_Secret_Endings.md`
- **Open:** the Doll README template words the field as "'Not my problem' / hidden path potential"; `Character_Creation_Overview.md` and `Alternate_Minmax_Endings.md` phrase the pillar as "Fuck you, not my problem."

### Accomplishment Weight System
- **Category:** game term
- **Also called:** History Points (the earlier TODO idea it formalizes)
- **Definition:** In Inner Tepenia, a tally of 0 to 100 History Points per companion, built from ordinary accomplishments, that paces her personal questline: at 100 (the Companion Trigger) the next gated step opens. Points run from 1 for discovering a location to 50 for reaching Idolized in a district meaningful to her; facts about the world count retroactively, site visits never do. Calethina's questline is the first worked example.
- **Status:** project canon (designed 2026-07-23; structure and values settled). Working: the Tier 2 thresholds and the gradual per-companion rollout.
- **Used in:** InnerTepeniaGDD; TepenianUniverseTimeline (Calethina's file); CurrentNovelDocs; DerivationMechanisms (copied methodology)
- **Sources:** InnerTepeniaGDD `Game-Mechanics/Core-Mechanics/Accomplishment_Weight_System.md`; `TODO.md`
- **Open:** whether these points are the same number as the History Points input of the Fragmentation Matrix is not confirmed.

### Action Points
- **Category:** game term
- **Also called:** AP
- **Definition:** In Inner Tepenia, the turn-based combat resource: a fresh pool each turn of 6 + floor(Agility/2), plus a Nerve modifier of floor((Nerve−5)/2) (−2 to +2), spent on movement (1 AP per tile), attacks, reloads, hacking and abilities. Engine adds floor((Engine−5)/2) free tiles, and unused AP is lost. *Outer Tepenia 1* takes New Vegas's real-time model instead, with AP gating the NODE targeting mode.
- **Status:** project canon for Inner Tepenia (corrected 2026-10-18: Engine 8 gives 1 free tile, Nerve 10 gives +2, and the "1 AP per 1.5 tiles" rule is dropped). Working: Outer Tepenia's costs and action list.
- **Used in:** InnerTepeniaGDD; Outer Tepenia 1 (fork); TorontoFellOutGDD; CurrentNovelDocs (reference copy)
- **Sources:** InnerTepeniaGDD `Game-Mechanics/Core-Mechanics/Action_Points_Base-Level_System.md`, `Game-Mechanics/Core-Mechanics/Core_Systems_Cleanup_Decisions_2026-10-18.md` and `README.md` (Action Point System); Outer Tepenia 1 `Game_Design_Principles.md` (AP Combat System)
- **Open:**
  - A separate Movement Points pool (optional rule 6) conflicts with the single pool and is left open.
  - The Outer Tepenia 1 copy of the base-level file still describes Inner Tepenia's turn-based version.

### Activation
- **Category:** robot biology
- **Definition:** The bringing online of a newly built, newly sentient robot, done with a fabrication-synthesis chamber; in Concordia the main activation site is Calethina's Engineering & Activation Lab. Robot character files record an activation date or window where a human file records a birth, and split a robot's life into Pre-Activation and Post-Activation. Waking a robot from flight mode is called reactivation.
- **Status:** Timeline canon for the usage; no repo gives a formal definition. Individual activation dates are mostly working.
- **Used in:** TepenianUniverseTimeline; InnerTepeniaGDD; CurrentNovelDocs (Maggie Aarden, Starlit Engines, root seed file); SouthernLights; TorontoFellOutGDD; Outer Tepenia 1; DerivationMechanisms

### Address axis
- **Category:** method term
- **Also called:** deficit address
- **Definition:** (Out of fiction) The ULM question of where the remedy for a place's deficit lives, which decides whether the place can perceive its own lack.
