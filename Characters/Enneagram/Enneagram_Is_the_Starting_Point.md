# Enneagram Is the Starting Point, Not the Result

**Status:** Confirmed, binding (author, 2026-10-29). It applies to every character in every project and medium, not to any one book or game. It is a mechanism for creating characters and their personal arcs (author, 2026-10-29).

**The law:** every character starts from the Enneagram type data, and none ends there. Each field is **extrapolated and adjusted** to the character herself and to her situation, environment, setting, time period and world. The fields include:
- type and wing;
- instinctual subtype;
- Basic Fear and Basic Desire;
- core weakness;
- wounding (childhood) message;
- passion and virtue;
- stress and growth lines.

The type data is never copied unchanged into a character's file.

**Why (the author's reasoning):**
- If the type data is never updated, every character of a type carries the same fear, "always the same."
- Take a Type 6, whose plain Basic Fear is "being without support or guidance." A reader who senses the type would know her fear before the story shows it, "the exact same thing as every other character like her."
- The author wants no character to be predictable from her type alone.

## How to apply
1. **Start from the type files.** The canonical mined Enneagram set is in `InnerTepeniaGDD/Worldspace/Enneagram/`, one folder per type; a copy sits beside this file in `from InnerTepeniaGDD/`. Record the plain type data as the cited **baseline**.
2. **Rewrite each field in the character's own terms:**
   - what the fear is *of*, specifically, in her life;
   - what sets it off;
   - how it shows, given her temperament and surface;
   - what it costs her;
   - what her era, place, society and status (robot or human, owned or free, where and when) make of it.
3. **Keep the type's structure recognizable.** A Six is still a Six; the law changes the form, object, triggers and expression of the type, not the type itself.
4. **Draw the differences from the character's own circumstances,** not from comparisons with other characters. Each work's cast stays independent.
5. **Mark the result as character-specific** in her file, with the baseline kept beside it.

## Self-check
- If a field in a character's file could be pasted onto any other character of the same type and still read as true, the field is not yet adjusted.
- If the adjusted field could be written without knowing her world (her era, place and circumstances), it is not yet extrapolated.
